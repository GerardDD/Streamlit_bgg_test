# Instruccions per a Claude

## Git
- Pregunta SEMPRE a l'usuari abans de pujar (push) o integrar canvis a la branca `main`, encara que t'hagi donat permís en una ocasió anterior. Cada push a `main` necessita una confirmació nova.
- Treballa a la branca de desenvolupament assignada i fes-hi push lliurement; només `main` requereix confirmació.
